# 六类产品落地页

用户批准共用版式、六个独立页面；先放样图，后续由用户供图替换。

- 保留现有六个网址，包含旧拼写 brkery-boxes。
- 模板：product-landing-page.tsx；独立内容：product-landing-data.ts。
- 每页：独立首屏、三种款式讨论方向、五项规格、两项产品注意事项、订购说明、四个独立 FAQ、预选类别询单、三个相关产品。
- 主图：public/sites/tasty/images/landing/ 下六张生成 WebP。均有示意说明；原产品图作为补充示意，未删除原件。
- 首页卡片 Get Custom Quote 指向相应产品页 #message；WhatsApp 图标消息携带类别。
- 各产品有独立标题、描述和规范网址。行业、About、Contact 网址保持不变。
- InquiryModule 和 LocalPreviewForm 只增加默认类别，仍不发送、不保存；Contact 默认不预选类别。
- 更换页面类别时询单模块通过产品 key 重建，避免沿用上一类的默认选择和状态。
- 供图要求及六张 PNG 样图位于项目外 交付文档/六类产品落地页供图/。
- 起订量、交期、材料适用、工艺、食品接触和负重要求没有写未经确认的承诺；纸袋样图不代表布袋能力已确认。

构建成功，六页电脑宽度 1280 和手机宽度 390 预览未出现横向溢出，主图加载、标题、FAQ 数量和预选类别已观察。未运行自动化测试或发送实际询单。发布结果另以 GitHub Pages 任务和线上页面为准。
